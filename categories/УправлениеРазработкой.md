# Управление разработкой

- Feature — причуда.
- Framework — костяк.
- API (Application Programming Interface) — Приложенческо-Програмный Циркуляр (ППЦ).  
- Cache — закрома.
- Roadmap — карта несбыточного.
- Sprint — рывок.
- Release — допуск в народ.
- Meeting - сход.
- Standup - стояние утреннее.
