# Код

```java
var xyz = 666L;
double fz168 = -100.0;
var progress = xyz * fz168;
```

# Пояснения

Компилятор Java может вывести, что `xyz` — длиннющий. А вирутальная машина Java проведет продвижение типов, и установит `progress` в тот же тип, что и `fz168`. Можно сказать, что `fz168` проводит `xuz`-ом по лбу `progress`-а.
